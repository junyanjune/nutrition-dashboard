# Elite Performance Lab — Athlete Nutrition Intelligence Dashboard

An interactive nutrition analytics dashboard for 15 elite athletes across 5 professional sports. Built with Chart.js (frontend) and Python/pandas (data layer).

---

## Live Dashboard

Open `dashboard.html` in any modern browser — no server, no install needed.

> Requires an internet connection on first load (Chart.js + Google Fonts via CDN).

---

## What's Inside

| File / Folder | Purpose |
|---|---|
| `dashboard.html` | Self-contained interactive dashboard (3 visualisations) |
| `analysis.py` | Python data pipeline — reads CSVs, computes metrics, generates `writeup.pdf` |
| `requirements.txt` | Python dependencies |
| `data/` | 20 relational CSV tables (athletes, meals, nutrition, sessions) |
| `writeup.pdf` | Full design & analysis report (generated by `analysis.py`) |

---

## Visualisations

### 1 · Body Composition Intelligence — *Bubble Chart with Hover*
Athletes plotted by **weight (X) vs body fat % (Y)**, bubble size = height. Colour-coded by sport. Hover any bubble for a rich tooltip card: name, sport badge, team, all body metrics, calorie bar, and macro breakdown (P / C / F).

### 2 · Macronutrient Profiles — *Radar Chart with Sport Toggles*
Radar chart comparing sport-average macros (Calories, Protein, Carbs, Fat). Five toggle pills animate datasets in/out with glow effects. Tooltip shows raw gram/kcal values.

### 3 · Session Analysis — *Animated Bar Chart*
Bar chart of all 15 athletes grouped by sport. Bar opacity encodes intensity (High / Moderate / Low). Controls:
- **Duration ↔ Calories** tab switches data with a smooth transition
- **▶ Replay** sequences bars in one-by-one (75 ms stagger)

## Setup (Python analysis + PDF)

```bash
# 1. Clone
git clone https://github.com/junyanjune/nutrition-dashboard.git
cd nutrition-dashboard

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run analysis — prints summary table and generates writeup.pdf
python analysis.py
```

Python 3.9+ required.

## Data Schema

The `data/` folder contains 20 CSV tables forming a relational nutrition database:

```
Athletes            → 15 athletes (name, DOB, position)
AthleteBodyMetrics  → weight, height, body-fat % per athlete
Sports / Teams / AthleteTeams → sport taxonomy and team membership
Meals / MealItems   → 30 meal records linked to food items
Foods / FoodNutrients / Nutrients → nutrient composition per serving
PerformanceSessions / PerformanceMetrics → session type, intensity, output
HydrationLogs / BeverageTypes → fluid intake per session
FoodCategories / Seasons / DataSources → reference tables
```
